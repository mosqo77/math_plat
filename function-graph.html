이차함수와 그래프의 성질 인터랙티브 탐구

계수 $a, b, c$를 조작하며 포물선의 개형, 꼭짓점의 이동, 대칭축, 판별식 $D$와 $x$축의 위치 관계를 실시간으로 관찰해 보세요.

개념 프리셋:
Function Plotter y = 1.0x² - 2.0x - 3.0
좌표 격자: 1칸 = 1 단위
꼭짓점 (Vertex) (1.0, -4.0)
축의 방정식 (Axis) x = 1.0
x축과의 교점 (Roots) (-1.0, 3.0)

🎛️ 계수 조작 컨트롤러 ($y = ax^2 + bx + c$)

이차항 계수 a (모양과 폭, 볼록 방향): 1.0
-4 (위로 볼록) 0 (직선 제외) +4 (아래로 볼록)
일차항 계수 b (축의 좌우 이동): -2.0
-6 (축 오른쪽) 0 (축이 y축) +6 (축 왼쪽)
상수항 c (y절편, 상하 평행이동): -3.0
-8 (아래로 이동) 0 (원점 지남) +8 (위로 이동)

🔍 판별식 $D = b^2 - 4ac$ 분석

D > 0 (서로 다른 두 실근)
판별식 계산값: D = 16.00

판별식 $D > 0$이므로 포물선이 $x$축과 서로 다른 두 점에서 만납니다.

D > 0
두 교점
D = 0
한 점 접함
D < 0
만나지 않음
💡

고1 수학 탐구 팁

표준형 변형: y = a(x - p)² + q 꼭짓점 $(p, q) = (-b/2a, -D/4a)$, 축 $x = -b/2a$
이차방정식과의 관계: $ax^2 + bx + c = 0$의 실근의 개수는 이차함수 그래프와 $x$축의 교점의 개수와 정확히 일치합니다.
