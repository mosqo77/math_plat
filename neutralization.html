산과 염기의 중화반응 적정 실험

비커 속 묽은 염산(HCl 20mL)에 수산화 나트륨(NaOH)을 첨가하며 지시약 색상, 이온 수의 변화, 최고 온도(중화점)를 관찰해 보세요.

지시약:
Virtual Experiment Apparatus 산성 용액 (pH < 7)
NaOH
총 20 mL
- 60mL - 40mL - 20mL
첨가한 0.1M NaOH 부피: 0 mL
0mL (시작) 20mL (중화점⭐) 40mL (과량)

🌡️ 실시간 반응 지표 (온도 & 지시약)

용액의 최고 온도 (중화열) 20.0 °C

* 완전 중화점(20mL)에서 중화열이 최대로 발생하여 온도가 가장 높습니다.

현재 지시약 색상 노란색 (산성)
BTB: 산성(노랑) → 중성(초록) → 염기성(파랑)

📊 용액 속 이온 수 변화

초기 HCl 분자 수: 10개 기준
수소 이온 (H⁺) : 알짜 이온 10개
수산화 이온 (OH⁻) : 알짜 이온 0개
염화 이온 (Cl⁻) : 구경꾼 이온 (일정) 10개
나트륨 이온 (Na⁺) : 구경꾼 이온 (계속 증가) 0개
💧 생성된 물 분자 (H₂O) 0개 (최대 10개)
💡

핵심 화학 반응식 & 시험 필수 포인트

알짜 이온 반응식 H⁺ + OH⁻ → H₂O

1:1 몰비로 결합하여 중화열을 발생시킵니다.

구경꾼 이온 Na⁺, Cl⁻

반응에 직접 참여하지 않고 용액 속에 그대로 남습니다.
